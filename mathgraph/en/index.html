Type an equation and it is drawn at once

Type y=sin(x) to get a graph, or A=(1,2) to get a point. Any letter you haven't defined becomes a slider, so you can change its value and watch the graph respond.

From constructions to calculus and probability

Hover over or tap an item to see it on screen.

  • Geometry constructionsDraw points, lines, circles, and polygons, then add midpoints, angles, and perpendicular bisectors.
  • Taylor approximationLayer degree 1, 3, 5, and 7 polynomials over sin(x) and see the fit improve.
  • Area under a curveShade the region between two points and compute the definite integral. Drag a point to change the interval.
  • Probability distributionsOverlay a normal curve on a binomial distribution, with sliders for n and p.

Drag a point and the shapes follow

mathgraph remembers which points and equations each shape was built from.

Dependent shapes move too

Drag a vertex and the sides, circles, and midpoints built from it are redrawn in place.

Attach points to shapes

Attach a point to a curve or segment and it stays on that path as you drag it.

Edit an equation, the rest updates

Change a curve's equation and the points and tangent lines on it follow the new curve.

Find any tool by name

Type a word like "circle", "integral", or "rotate" in the search box at the top to find the tool you need.

Frequently asked questions

Do I need to install anything?
No. Open the address in a web browser and start.
Where is my work saved?
It is saved automatically in the browser you are using. To continue on another device, export a .json file and open it there.
Where can I learn how to use it?
The help page explains how to type equations and what each tool does.
How much does it cost?
mathgraph is a paid service. Email iworkonlabs@gmail.com for terms.
